Machine Learning — Optimization Problem

Consider the objective function L(θ)L(\theta) = \frac{1}{2m} \sum_{i=1}^m (h_\theta(x^{(i)}) - y^{(i)})^2L(theta).

The gradient descent update rule implemented in Python is shown below:

def gradient_step(theta, alpha, grad):
    # Update parameters along steepest descent
    return theta - alpha * grad
