Consider the following Python function:

def mystery(lst):
    if len(lst) <= 1:
        return lst
    pivot = lst[0]
    left = [x for x in lst[1:] if x <= pivot]
    right = [x for x in lst[1:] if x > pivot]
    return mystery(left) + [pivot] + mystery(right)

What is the return value of mystery([4, 2, 7, 1, 3])?
