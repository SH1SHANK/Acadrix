Start locally

Install the extension in a few deliberate steps.

Acadrix currently supports an unpacked Chromium extension workflow. There is no Chrome Web Store listing to install from.

Check published releases ↗
  1. 01

    Get the source

    Clone the repository and install its locked dependencies.

    git clone https://github.com/SH1SHANK/Acadrix.git
    cd Acadrix && npm ci
  2. 02

    Build the extension

    Generate the unpacked extension bundle.

    node build.mjs
  3. 03

    Load it in Chrome

    Open chrome://extensions, enable Developer mode, choose Load unpacked, and select build/.
